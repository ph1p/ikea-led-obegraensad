# Plugins

A plugin owns the display while it is active. Only one plugin runs at a time. You can switch
plugins with the button, the [Web GUI](/usage/web-gui), the [HTTP API](/reference/http-api#set-the-active-plugin),
the [WebSocket](/reference/websocket) or [MQTT](/integrations/mqtt).

## Plugin IDs

IDs are assigned in the order in which the plugins are registered in `src/main.cpp`, starting
at 1. The table below shows the IDs of the default build.

:::warning
IDs change when plugins are added, removed or disabled. Scripts and automations should read the
current list from [`GET /api/info`](/reference/http-api#device-info) or use the plugin name, which
the MQTT `plugin/set` topic also accepts.
:::

## Notable plugins

### Clocks

**Clock**, **Big Clock**, **Ticking Clock**, **PongClock**, **SmokeClock** and **FractalClock** show
the local time. Set your time zone in **Settings → Time**, otherwise the time is off by your UTC
offset.

### Weather

Shows the temperature and a weather icon from [wttr.in](https://wttr.in/). Set the location in
**Settings → Weather**.

### Draw

A canvas that you paint from the Web GUI or the WebSocket API. The drawing can be saved to storage.

### Animation

Plays frames that you create in the **Animation Creator** of the Web GUI or upload through the
[WebSocket](/reference/websocket#animation-plugin).

### DDP and ArtNet

Receive frames from the network. See [DDP](/integrations/ddp) and [Art-Net](/integrations/artnet).

## Startup plugin

The plugin that was active when you saved it as the startup plugin (**persist-plugin** in the
Web GUI) is activated at boot and on a long button press. Alternatively the
[plugin schedule](/usage/scheduler) can start on boot.
